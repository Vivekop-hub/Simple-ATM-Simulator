# Simple ATM Simulator 🏧

## About
This is my first Python mini project. I created a simple ATM simulator to practise Python programming.

## Features
- PIN-based user login
- Check account balance
- Deposit money
- Withdraw money
- Exit option
- Three PIN attempts

## Concepts Used
- Python Functions
- If-Else Conditions
- While Loop
- Return Statement
- User Input

## How to Run

1. Install Python.
2. Download this repository.
3. Open the terminal.
4. Run:

```bash
python atm.py
```
